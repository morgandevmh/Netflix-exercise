# Netflix Homepage Clone

Learning exercise for **HTML & CSS layout techniques**

## 🎯 Objective

**Main goal**: Reproduce the Netflix landing page (logged-out state) as faithfully as possible while applying modern CSS layout techniques and best practices learned in class.

**Context**: This exercise focuses on mastering complex UI layouts, responsive design patterns, and CSS styling by reverse-engineering a professional interface. It reinforces fundamental HTML/CSS skills through practical application.

## 🧠 Key Learnings

- **Technical concept mastered**: CSS Grid and Flexbox for complex multi-section layouts
- **Common mistake identified**: Over-relying on absolute positioning instead of using semantic layout techniques
- **Best practice applied**: Mobile-first responsive design with semantic HTML structure

## 🔁 Process & Reflection

1. **Initial approach**: Analyzed Netflix's landing page structure and planned section-by-section reproduction
2. **Obstacles**: Matching exact spacing, gradients, and responsive breakpoints without access to source code
3. **Resolution**: Used browser DevTools to inspect elements and recreate visual effects through CSS
4. **Retrospective**: Would start with a more detailed wireframe and component breakdown before coding

## 🛠 Tech used

- HTML5
- CSS3 (Flexbox, Grid)
- Responsive Design (media queries)
